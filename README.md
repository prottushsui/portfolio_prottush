# Mottakin Bin Arif Prottush — Portfolio\n\nPersonal portfolio for Md. Mottakin Bin Arif Prottush, built with React and Vite. The site presents software prototypes, research interests, and a direct contact workflow without placeholder projects or invented metrics.\n\n## Stack\n\n- React 19\n- Vite 8\n- Modern CSS\n- Intersection Observer for active-section navigation\n\n## Run locally\n\n```bash\nnpm install\nnpm run dev\n```\n\nProduction build:\n\n```bash\nnpm run build\nnpm run preview\n```\n\n## Content\n\nThe portfolio currently highlights ShasthoLink, Study Material Library, and ongoing independent research into Bangladesh's Muslim personal-law and property-law framework. Project descriptions are intentionally limited to work and research discussed by the owner rather than invented metrics or placeholder claims.\n\n## Contact\n\nThe contact form opens a pre-filled email draft in the visitor's default mail client. No server-side form handling or personal-data storage is implemented.\n\n## License\n\nMIT\n
